## 本分类的统一写作结构

每篇专题原则上按照以下顺序设计，具体内容不预先填充：

1. 快速理解：定义、问题、核心结论和示意图。
2. 背景与问题：技术出现的原因和待解决瓶颈。
3. 核心原理与理论基础：概念、公式、推导、假设和局限。
4. 工程实现：实现机制、软件栈、硬件映射和关键参数。
5. 经典项目与案例：关联独立项目档案、论文和源码。
6. 实验与性能验证：指标、基线、测试条件和分析方法。
7. 我们的理解与研究问题：个人理解、待验证假设和研究方向。
