## 统一写作结构

1. 快速理解：定义、问题、核心结论和示意图。
2. 背景与问题：精度、吞吐、显存和稳定性之间的矛盾。
3. 核心原理与理论基础：数值格式、误差定义、推导和适用条件。
4. 工程实现：数据类型、累积策略、量化与硬件支持。
5. 经典项目与案例：Transformer Engine、混合精度训练、量化推理等。
6. 实验与性能验证：误差指标、任务质量、收敛性和性能。
7. 我们的理解与研究问题：精度—性能权衡和稳定性边界。

## 分类边界

本类关注数值表示及误差约束。单纯为了性能改变数据布局属于内存或 Kernel 优化；只有涉及数值格式、舍入、误差和稳定性时才归入本类。
